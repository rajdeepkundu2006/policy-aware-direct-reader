`PROJECT_CONTEXT.md`, `IMPLEMENTATION_PLAN.md`, `TEAM_AI_HANDOFF.md`, `INTERFACE_CONTRACT.md`, `POLICY_AST_HANDOFF.md` and `PaperA_Draft.docx` preserve the original team plan and handoffs. Some planned capabilities differ from the final restricted implementation; consult the root README for its current scope and run instructions.
